# PigCloud Issue Tracker

The public issue tracker for everything PigCloud. The code repositories are
source mirrors with issues disabled, so bug reports and feature requests for
all apps belong here.

| Product | Where |
|---------|-------|
| Web app | [pigcloud.de](https://pigcloud.de) |
| CLI | [pigcloud-cli](https://github.com/pigtech-de/pigcloud-cli) |
| Desktop sync | [pigcloud-sync](https://github.com/pigtech-de/pigcloud-sync) |
| Mobile app | [pigcloud-mobile](https://github.com/pigtech-de/pigcloud-mobile) |
| TEE scanner | [pigcloud-tee](https://github.com/pigtech-de/pigcloud-tee) |

When filing, name the product and its version (`pc vr` for the CLI, the About
dialog for desktop, or the release tag).

For quicker response times, contact us directly: contact@pigtech.de.

Please report security vulnerabilities by email, never as public issues.
